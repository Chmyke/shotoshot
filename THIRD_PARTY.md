# Third-party dependencies

Shotoshot is distributed under **GPL-3.0-only** (`LICENSE`, workspace `license` field). Every
dependency must remain usable in a GPL-3.0 program: `check-licenses.ps1`, run by `check.ps1`,
reads the declared license of each crate of the tree (every target, build and test dependencies
included) and fails on an identifier that has not been reviewed. The list of accepted identifiers
lives in that script; adding one is a decision, not a formality. The exact resolution is in
`Cargo.lock`.

`shotoshot-core` and `shotoshot-ui` have no dependency. There is no web engine, and no external
drawing library on Windows, which uses Direct2D.

## Direct dependencies

| Crate | Platform | Role | Declared license |
|---|---|---|---|
| windows, windows-numerics | Windows | Windows API, Direct2D math types | MIT OR Apache-2.0 |
| tiny-skia | Linux, macOS | paths and fills | BSD-3-Clause |
| cosmic-text | Linux, macOS | text layout and rendering, font fallback | MIT OR Apache-2.0 |
| zbus | Linux | D-Bus, screenshot portal | MIT |
| png | Linux | PNG decoding and encoding | MIT OR Apache-2.0 |
| winit | Linux | capture window | Apache-2.0 |
| softbuffer | Linux | presents the frame without a GPU stack | MIT OR Apache-2.0 |
| arboard | Linux | clipboard | MIT OR Apache-2.0 |
| ksni | Linux | notification-area icon | Unlicense |
| x11rb | Linux | direct screenshots on X11 | MIT OR Apache-2.0 |

The portable renderer (tiny-skia, cosmic-text) is pure Rust and is absent from the Windows binary.

## Embedded font

Text annotations are set in **Roboto Medium**, embedded in the binary on every platform so that
they look the same everywhere. It is distributed under the **SIL Open Font License 1.1**, which
allows bundling with software under any license; its text ships with every package
(`THIRD-PARTY-NOTICES.txt`) and lives in `crates/shotoshot-ui/assets/Roboto-OFL.txt`, next to the
note on where the file comes from. The interface itself uses the system font.

## Full tree

As of 2026-10-09 (`cargo tree --workspace --target all`): 296 third-party crates, all under a
permissive license: MIT, Apache-2.0 (with or without the LLVM exception), BSD-2-Clause,
BSD-3-Clause, ISC, Zlib, 0BSD, Unlicense, BSL-1.0 and Unicode-3.0. Two crates also offer a
copyleft license and are used under their permissive option: `self_cell` (Apache-2.0 OR
GPL-2.0-only, used under Apache-2.0) and `r-efi` (MIT OR Apache-2.0 OR LGPL-2.1-or-later, used
under MIT).

Macros and their dependencies take part in the build. Their presence in `Cargo.lock` does not mean
that an additional runtime is shipped with the binary.

## Distributed notices

Windows: `packaging/THIRD-PARTY-NOTICES.txt` (windows-rs and the embedded font), installed with
the application. Linux: notices generated by `packaging/build-linux.ps1` from the license files of
every crate linked into the binary, followed by the license of the embedded font.

Both packages also carry `LICENSE.txt` (this project's license) and `ABOUT.txt`
(`packaging/ABOUT.txt`: copyright, license notice and the link to this repository). The package
builders read their output back and refuse a package that lacks one of them.

Sources: [windows-rs](https://github.com/microsoft/windows-rs) and the manifests of the crates
downloaded by Cargo.
