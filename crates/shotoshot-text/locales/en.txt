# Shotoshot interface texts, English: the source. This file defines the keys and their order.
#
# Format: UTF-8 without BOM, one entry per line, `key = text`. `#` starts a comment line.
# Key: lowercase letters, digits and `_`, dot-separated (`toolbar.rectangle`).
# Text: trimmed; `\n` is a line break, `\\` a backslash; `{name}` is a variable that every
# language must keep, with the same name. Never build a sentence from pieces: one key, one
# whole sentence.
# In another language, `key == text` declares a text that stays identical to the English on
# purpose (proper name, "OK", an extension). Without `==`, a copy of the English fails the build.
